### Now building: [Elifba](https://github.com/nijataliyev7/elifba)

Free, open-source reading games for Azerbaijani primary classrooms. The game runs on the classroom wall, the teacher drives it from a phone, and children never need an account. Live at **[elifba.io](https://elifba.io)**.

<a href="https://github.com/nijataliyev7/elifba"><img src="https://github.com/nijataliyev7/elifba/raw/main/docs/screenshots/demo.gif" width="720" alt="Elifba in a lesson: the teacher taps the answer on the phone remote and the balloon with that letter bursts on the classroom wall"></a>

- **Stack:** Laravel 13, Inertia 3, React 19, TypeScript, Tailwind 4, Phaser for the board, Laravel Reverb for the live phone remote
- **Quality:** PHPStan level 8 with no baseline, Pest on SQLite and PostgreSQL 17, Vitest; CI runs all of it
- **Privacy by design:** a child is a first name and an avatar; no third-party scripts, fonts or analytics
- **Self-hostable:** one `docker compose` stack with Caddy, PostgreSQL, Reverb and nightly backups

Help is welcome, from teachers too: see the [good first issues](https://github.com/nijataliyev7/elifba/labels/good%20first%20issue).
